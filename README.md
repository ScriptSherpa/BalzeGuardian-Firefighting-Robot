# 🤖 BalzeGuardian - Firefighting Arduino-Based Robot

**BalzeGuardian** is a smart, Arduino-powered firefighting robot designed to detect and extinguish small fires in hazardous environments. It is equipped with flame sensors, obstacle detection, a water pump system, and autonomous navigation capabilities. This project aims to provide a low-cost, efficient solution for basic fire safety applications in homes, labs, and small industrial setups.

---

## 🚀 Features

- 🔥 **Flame Detection** using IR Flame Sensors  
- 🧭 **Obstacle Avoidance** using Ultrasonic Sensors  
- 💧 **Automated Water Spraying Mechanism**  
- 🧠 **Arduino UNO Controlled System**  
- 🔋 **Battery-Powered Operation** with Efficient Power Management  
- 🔄 **Autonomous Fire Navigation**  

---

## 🔧 Hardware Components

| Component             | Description                       |
|----------------------|-----------------------------------|
| Arduino UNO          | Main microcontroller board        |
| IR Flame Sensor      | Detects the presence of fire      |
| Ultrasonic Sensor    | Detects and avoids obstacles      |
| L298N Motor Driver   | Drives the motors                 |
| DC Motors            | Moves the robot chassis           |
| Water Pump           | Sprays water to extinguish fire   |
| Relay Module         | Controls the water pump switching |
| Li-ion Battery       | Powers the entire system          |
| Chassis + Wheels     | Robot base and movement platform  |
| Jumper Wires         | For connections                   |
| 3D Printed Parts     | Custom-designed chassis/mounts    |

---

## ⚙️ How It Works

1. **Flame Detection:** Continuously scans surroundings for fire using IR flame sensors.  
2. **Navigation:** If fire is detected, it moves toward the flame while avoiding obstacles using ultrasonic sensors.  
3. **Fire Extinguishing:** Once in range, it activates the pump and sprays water.  
4. **Reset:** Returns to search mode after extinguishing the fire.
