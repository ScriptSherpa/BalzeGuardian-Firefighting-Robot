# 🤖 BalzeGuardian - Firefighting Arduino-Based Robot

**BalzeGuardian** is a smart, Arduino-powered fire-fighting robot designed to detect and extinguish flames in hazardous environments. Built with IR sensors, flame detectors, motors, and a water pump system, it's an ideal automation project for fire safety research and robotics enthusiasts.

---

## 🚀 Features

- 🔥 Flame Detection using IR Flame Sensors
- 🧭 Obstacle Avoidance using Ultrasonic Sensors
- 💧 Automated Water Spraying Mechanism
- 🧠 Arduino UNO Controlled System
- 🔋 Battery-Powered with Efficient Power Management

---

## 🔧 Hardware Components

| Component             | Description                |
|-----------------------|----------------------------|
| Arduino UNO           | Main microcontroller       |
| IR Flame Sensor       | Flame detection            |
| Ultrasonic Sensor     | Obstacle detection         |
| Motor Driver (L298N)  | Controls motor directions  |
| DC Motors             | Robot mobility             |
| Water Pump            | For fire extinguishing     |
| Relay Module          | Pump control               |
| Battery (Li-ion)      | Power source               |

---

## 🛠️ How It Works

1. The robot constantly monitors the environment for flames using IR flame sensors.
2. If a flame is detected, it moves towards the source while avoiding obstacles.
3. Once near the flame, the water pump activates and extinguishes the fire.
